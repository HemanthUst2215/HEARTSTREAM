1. Inputs used

Trusted factory rules plus workshop material. One-time setup data is not used at runtime once the playbook is active.

📝

Workshop transcript

Recorded discussion text. Requirements are traced to what was actually said. Content is screened before extraction.

📖

Story playbook

Column layout, work item types, and narrative patterns for Azure DevOps export—the single formatting contract.

📈

Epic & Feature catalog

Approved hierarchy titles and identifiers. Stories attach to existing features; new epic names are not invented.

🗃

Work item registry

Structured catalog of workshops, epics, and features used when attaching IDs to the final story workbook.

Requirements & acceptance criteria

  • Stories — Short title, role-based description, and bullet acceptance criteria tied to the transcript.
  • Feature first — Match the workshop topic to a catalog feature before writing the story.
  • Testable criteria — One observable outcome per line, including limits and negatives when the session stated them.

4. Epic & Feature mapping

During authoring teams identify which catalog feature owns the requirement. After validation the system writes epic and feature rows and links each story to the right feature.

flowchart TB subgraph during [During authoring] TR[Workshop topic] --> IDF[Pick catalog feature] IDF --> US[Write story text] end subgraph after [After validation] US2[Story rows] --> SC[Score title match] SC --> SM{Strong match?} SM -->|yes| FE[Add epic and feature rows] SM -->|yes| SID[Link story to feature] SM -->|no| BL[Leave link empty] end during --> after

Traceability

  • Each story cites where in the workshop it came from.
  • Mapping records which rows matched the catalog.
  • Hierarchy in the workbook supports import and quality review.

5. Work item mapping

The mapper reads the work item registry, scores each story against catalog features, and writes identifiers without changing story wording.

Load catalog

Epics, features, and workshops with titles, descriptions, and parent links.

Score matches

Title similarity and topic relevance with a strong-match threshold—no guessed IDs.

Publish workbook

One deliverable with catalog epic and feature rows plus linked stories.

Resolve epics

Each feature must roll up to a parent epic in the same catalog.
