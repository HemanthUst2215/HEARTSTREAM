Generated-only Stories (Valid Extras vs Noise)

Generated User Story rows with no manual match. valid_extra: the transcript states the requirement and the manual CSV does not. noise: the transcript does not state the requirement, or the row restates no distinct requirement. Classification must cite hallucination-detection-evaluator evidence. Disagreement between the two subagents is BLOCKED_CONFLICT, not an average.

epic-feature-mapping-evaluator

Epic Agreement

0% (0/5)

Matched pairs whose epic context agrees, divided by matched pairs where both sides have an epic context (preceding Epic row, else blank). Agree when Epic ID is equal and non-blank, or when both IDs are blank and the Epic titles are the same string. Pairs with epic context on only one side count as disagree. Zero comparable pairs → na.

epic-feature-mapping-evaluator

Feature Agreement

0% (0/5)

Matched pairs whose feature context agrees, divided by matched pairs where both sides have a feature context (preceding Feature row, or the User Story ID when that ID is the catalog Feature work item id). Agree when Feature ID is equal and non-blank, or when both IDs are blank and the Feature titles are the same string. One-sided context counts as disagree. Zero comparable pairs → na.

acceptance-criteria-evaluator

Acceptance Criteria Quality

84

Mean of per-story quality scores on generated User Story rows. A bullet scores only when it is one observable outcome, testable from the transcript, and the cell uses ASCII "- " bullets (rulebook acceptance_criteria.format). Score is 0-100. Do not award points for implementation detail.

acceptance-criteria-evaluator

Negative and Boundary Coverage

100% (17/17)

Generated User Story rows whose Acceptance Criteria include the negative or boundary outcome the transcript states for that requirement, divided by generated User Story rows whose matched transcript span states a negative or boundary. When the transcript states none, na.

story-matching-evaluator

Granularity

86% (25/29)

Generated User Story rows that state exactly one capability, divided by generated User Story rows. A split or merge recorded on a match is evidence of a granularity miss for every generated row in that match that stacks or fragments a capability.

hallucination-detection-evaluator

Hallucination Rate

21% (6/29)

Generated User Story rows that contain at least one claim the transcript does not support, divided by generated User Story rows. Every counted row needs a transcript locator showing the absence of support (the nearest related span, or an explicit note that no span exists). Unsupported epic or feature titles count as hallucinations.
