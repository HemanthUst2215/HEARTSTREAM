epic-feature-mapping-evaluator

Epic Agreement

0% (0/5)

Matched pairs whose epic context agrees, divided by matched pairs where both sides have an epic context (preceding Epic row, else blank). Agree when Epic ID is equal and non-blank, or when both IDs are blank and the Epic titles are the same string. Pairs with epic context on only one side count as disagree. Zero comparable pairs → na.

epic-feature-mapping-evaluator

Feature Agreement

0% (0/5)

Matched pairs whose feature context agrees, divided by matched pairs where both sides have a feature context (preceding Feature row, or the User Story ID when that ID is the catalog Feature work item id). Agree when Feature ID is equal and non-blank, or when both IDs are blank and the Feature titles are the same string. One-sided context counts as disagree. Zero comparable pairs → na.
